## Task Overview
The class competition focuses on deciding whether two text segments, combined using the marker [SNIPPET], are written by the *same author (1)* or by *different authors (0)*.  
This is a binary authorship-identification problem, and each example includes:
- *ID*  
- *TEXT* (two spans merged together)  
- *LABEL* (only in the training set)

The dataset is provided in CSV format and includes train.csv, test.csv, and a sample_submission.csv template.

---

## Team Approach (Baseline)
Our team built an initial baseline system together, and the model training was carried out in a shared Kaggle notebook environment.

### Main steps taken:
1. Uploaded the dataset files to Kaggle.  
2. Loaded the data using pandas.  
3. Preprocessed the text using a *TF–IDF vectorizer*, with both:
   - word-level n-grams (1–2)  
   - character-level n-grams (3–5)  
4. Trained a *Logistic Regression* model with balanced class weights.  
5. Verified performance through a small validation split.  
6. Retrained on the full dataset and generated predictions for the test set.  
7. Exported the predictions as submission.csv and submitted them to the leaderboard.

This version serves as our team’s first valid submission.
