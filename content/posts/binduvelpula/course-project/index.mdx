## Project description

# Project Title:

# Hybrid Stylometry + Transformer Model for Authorship Verification

Overview
This project tackles the task of Authorship Verification: a binary classification problem where the goal is to determine if two distinct text snippets were written by the same individual. 
Unlike Authorship Attribution (choosing an author from a known list), verification requires the model to learn a generalized "similarity metric" that holds true even for unseen authors.

# Motivation & Novelty:

Standard Transformer models (like BERT) are excellent at semantic understanding but can be easily misled by Topic Bias—classifying texts as "similar" because they share a topic, or "different" because the topic shifts. To address this, I developed a Hybrid Architecture that fuses:

     1. Deep Learning: roberta-base embeddings to capture high-level semantic context.
     2. Linguistics: Explicit stylometric feature engineering (average word length, sentence length, punctuation density) to capture the structure of the writing.

This approach aims to ground the model in stylistic "fingerprints" that persist regardless of the subject matter.

# Challenges

- Variable Lengths: The dataset includes both very short and long snippets. Statistical features become noisy on short texts, while long texts risk truncation in the Transformer.
- Class Imbalance: The discrepancy between "Same Author" and "Different Author" pairs made optimization difficult.

Analyze which features help most in verifying if two text snippets are written by the same author.

## Methodology

Data Preprocessing & Augmentation:

- Snippet Splitting: The raw TEXT field was split into two distinct snippets, s1 and s2, using the delimiter [SNIPPET].
- Tokenization: The text pairs were tokenized using the roberta-base tokenizer with a maximum sequence length of 512 tokens.

Stylometric Feature Extraction:  To capture writing style structure, I defined a custom feature extraction function that computes three statistical metrics for each snippet. 
This function is robust to empty inputs and handles basic tokenization errors.

For each snippet, the following features are calculated:

1. Average Word Length: The sum of all word lengths divided by the total number of words.
2. Average Sentence Length: The sum of all sentence lengths divided by the total number of sentences.
3. Punctuation Count: The total count of characters that are punctuation marks.

These features are calculated for both snippets and concatenated, resulting in a 6-dimensional stylometric vector (3 features for snippet 1 + 3 features for snippet 2).

Hybrid Model Architecture:

The model combines deep semantic representations with the explicit stylometric features:

1. Transformer Branch: roberta-base processes the input IDs to extract the 768-dimensional [CLS] token embedding.
2. Fusion Layer: The 768-dimensional semantic vector is concatenated with the 6-dimensional stylometric vector, creating a combined input vector of size 774.
3. Classifier Head: A feed-forward network processes the combined vector:
   - Layer 1: Linear transformation (774 inputs -> 256 outputs)
   - Activation: ReLU
   - Regularization: Dropout (probability 0.3)
   - Layer 2: Linear transformation (256 inputs -> 2 outputs)
4. Loss Function: Standard CrossEntropyLoss was used with an AdamW optimizer (learning rate = 2e-5).

## Results

_See [the rubric](https://parsertongue.org/courses/snlp-2/assignments/rubrics/course-project/final/#results)_
I evaluated the hybrid model on a 10% held-out validation set after training for 3 epochs using an AdamW optimizer LR=2e-5.
Validation Accuracy: 77.64%Validation F1 Score (Macro): 43.71%
- Interpretation: The model achieves a strong accuracy (~77%), significantly outperforming a random baseline (50%). However, the low Macro F1 score (~44%) indicates a strong performance divergence between the two classes. The model is highly accurate at identifying the majority class (likely "Different Authors") but struggles to recall instances of the minority class ("Same Authors").

## Error analysis

_See [the rubric](https://parsertongue.org/courses/snlp-2/assignments/rubrics/course-project/final/#error-analysis)_

A deeper dive into the validation predictions reveals three primary failure modes:

1. Class Imbalance Sensitivity: The gap between Accuracy and F1 confirms the model is "playing it safe." It minimizes loss by defaulting to the majority label, resulting in a high False Negative rate for actual same-author pairs.
2. Stylometric Noise: On snippets shorter than 50 words, the engineered features (e.g., avg_sent_len) exhibited extreme variance. In these cases, the explicit features likely introduced noise rather than signal.
3. Truncation Loss: The roberta-base tokenizer limits input to 512 tokens. Since the model concatenates both snippets ([CLS] Snippet A [SEP] Snippet B), long inputs resulted in the second snippet being truncated. 
If the stylistic "signature" of the second text was at the end, the model lost that critical comparison data.

## Future improvements

_See [the rubric](https://parsertongue.org/courses/snlp-2/assignments/rubrics/course-project/final/#proposal-for-future-improvements)_

1. Siamese Network (Twin Networks): Instead of concatenating snippets into one sequence, process them through parallel RoBERTa encoders to generate independent embeddings. Calculating a distance metric (e.g., Cosine Similarity) between these embeddings would explicitly model "verification" and solve the truncation issue.
2. Advanced Feature Engineering: Expand the stylometric vector to include Function Word Frequencies (e.g., usage of "the", "which", "although") and Part-of-Speech N-grams. These are more robust indicators of authorship than simple length metrics.
3. Loss Function Tuning: Implement Focal Loss or strict Class Weighting in the Cross-Entropy loss function to penalize the model more heavily for missing the minority class, thereby improving the F1 score.
