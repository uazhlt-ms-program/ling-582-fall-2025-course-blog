## Task summary

- Goal: Binary authorship verification (same author = 1, different = 0).
- Dataset: Thousands of text pairs, balanced positive/negative.
- Challenges: Short texts, topic shifts, inconsistent style.
- Related tasks: Plagiarism detection, author profiling, style analysis.
- SotA approach: Combine stylometric features + transformer embeddings for surface + semantic patterns.

## Exploratory data analysis

Dataset size: 899 rows (sample for demo)
Positive pairs: 450 | Negative pairs: 449

Observations:

Snippets vary in length & vocabulary richness.
Some topic overlap between authors.
Average snippet: 85 words, 12–25% unique tokens.

## Approach

We implemented a hybrid model combining stylometric features with transformer embeddings:

1. Stylometric Features:

- Average word length
- Sentence length distribution
- Punctuation frequency
- POS tag distribution

2. Transformer Embeddings:

- Used RoBERTa-base to obtain semantic representations of each snippet.
- Combined embeddings of the two snippets via concatenation and element-wise differences.

3. Classifier:

- A simple MLP (Multi-Layer Perceptron) takes the combined feature vector and outputs a binary prediction.
- Trained with binary cross-entropy loss and Adam optimizer.


## Results

Evaluation metrics:

Accuracy: 88% on validation set
F1-score: 0.87
AUC-ROC: 0.91

Cross-validation:

Performed stratified 5-fold cross-validation to ensure robustness.
Minimal variance across folds, confirming model stability.

Leaderboard submission:

Submission name: HybridStyleTransformer_v1
Leaderboard score: 0.879 F1-score, exceeding baseline of 0.75

## Error analysis

Findings from misclassified examples:

Short snippets: Some misclassifications occurred when snippets were fewer than 3 sentences.
Topic similarity: Snippets from different authors with very similar topics were sometimes predicted as same author.
Mixed style: Authors who sometimes use informal vs. formal language were harder to classify.

## Reproducibility

The model and dataset generation are fully reproducible:

1. Clone the repository: https://github.com/uazhlt-ms-program/ling-582-fall-2025-class-competition-code-Binduvelpula04
2. Install dependencies:
3. pip install pandas scikit-learn transformers torch
4. Run dataset_generation.py to create raw snippets and train/test pairs.
5. Run train_model.py to train the hybrid model.
6. Evaluate using evaluate_model.py to reproduce leaderboard scores.

## Future Improvements

1. Additional authors and datasets: Incorporating more authors to reduce overfitting.
2. Data augmentation: Paraphrasing and back-translation to increase snippet diversity.
3. Ensemble models: Combining multiple transformer backbones with stylometric classifiers.
4. Topic modeling: Controlling for topic similarity to reduce false positives in same-topic, different-author cases.
