## Description

The paper presents a "universal" neural machine translation (NMT) for extremely low resource languages. The main approach is maximizing transfer learning and representation sharing across multiple languages. The author introduce Universal Lexical Representations (ULR) and Mixture of language Experts (MoLE). ULR is a shared multilingual embedding space across all source languages, the low resources benefit from these shared embeddings. MoLE, intuitvely, each model has it's own shared expert encoder of each of the source languages. These two methods combined encourage lexical and sentence level sharing mkaing it possible to effectively train machine translation for a target language with almost no parellel data.

#### What problems remain and what are the next steps?

Jacob Devlin's work on Universal Neural Machine Translation (UNMT) for extremely low-resource languages is a significant advancement in the field of machine translation. 2. **Model architecture:** Current models, such as UNMT, rely on transformer architectures, which can be computationally expensive. Developing more efficient models that can handle low-resource languages without sacrificing performance is essential.

5. **Ambiguity and disambiguation:** Languages often have ambiguous words or phrases, which can lead to incorrect translations. Developing methods to disambiguate such cases is crucial.
