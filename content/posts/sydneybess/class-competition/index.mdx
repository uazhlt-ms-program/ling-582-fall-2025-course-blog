## Task summary

_See [the rubric](https://parsertongue.org/courses/snlp-2/assignments/rubrics/class-competition/final/#task-summary)_

The goal of this task is to see if two texts are by the same or different authors.  First task was to examine the datasets and read them into a dataframe.

The first thing I tried was to find cosine similarity, but that performed awfully. I was going to try word embeddings but after looking at the data, it wasn't necesarily the _words_ that made them same authors, but other features.

So, to be brief and not give away my competitive edge 😏 I ended up following some guides from HuggingFace to run a Sequence Classifier model and using Transformer tokenizers to encode the text. 

I chose Sequence Classifier because because a sequence2sequence based model is more effective then logistic regression and uses attention mechanisms to better find the important features to tell the differences.

In terms of tokenizers, I chose my specific tokenizer I did because it is considered leading in tokenizers and was suggested for text classification.

My next move will be to add more augmented data to better train the model and mess around with parameters and maybe different pre-trained models.

## Approach

_See [the rubric](https://parsertongue.org/courses/snlp-2/assignments/rubrics/class-competition/final/#approach)_
My approach was to use a text classifier BERT model to classify the texts. 
1. Performed exploratory analysis and decided to add two new columns for each of the text snippets. This is also where I attempted to supplement with more data.
2. Seperated the dataframe into train and test and imported it into a Dataset for easier manipulation
3. Set up the tokenizer, I used bert-base-uncased as that was suggested by [Text classifier](https://huggingface.co/docs/transformers/en/tasks/sequence_classification)
    For this I mapped the dataset and did some alterations for the model to better understand, such as renaming 'LABEL' and ignoring the actual texts columns and focusing on the IDs, input_ids, token_type_ids, attention_mask, and labels.
    Next I put it in the format of torch based on this example [Dealing with tokenizer](https://huggingface.co/docs/datasets/en/process)

4. Next I set up a data_collator with dynamic padding to better organize padding
5. Creating a metric to test the success of the model using accuracy, function taken from [Text Classifier](https://huggingface.co/docs/transformers/en/tasks/sequence_classification)
6. Set up the training arguments as suggested by [Text Classifier](https://huggingface.co/docs/transformers/en/tasks/sequence_classification). My initial run was 3 num epochs, but I thought if I ran it longer it would be better - but that was not the case. I was *trying* to be novel and try new things, but HuggingFace knows what it is talking about. But at least I learned what didn't work as well (though all my experimentations did help me learn more about my model, and were relatively close to eachother ie 65%-67% compared to the top first model which was 70%)
