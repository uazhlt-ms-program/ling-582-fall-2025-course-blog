## Project description

_See [the rubric](https://parsertongue.org/courses/snlp-2/assignments/rubrics/course-project/final/#reproducibility).  Use subsections to organize components of the description._

Minimal Chain-of-Thought (COT) prompting has been studied primarily in high-resource languages such as English. These studies show that, despite using shorter reasoning steps and requiring less inference time, minimal COT achieves performance comparable to standard COT while improving efficiency. In this project, we aim to investigate the effectiveness of minimal COT in a low-resource language setting, focusing specifically on Nepali.
