## Task Summary

The goal of the LING 582 class competition is to decide whether two text spans, joined by the special token `[SNIPPET]`, were written by the **same author (label = 1)** or by **different authors (label = 0)**. This is a binary classification problem related to authorship attribution, authorship verification, and stylometry.

The dataset is provided in CSV format and consists of three files:

- `train.csv` – labeled training set  
- `test.csv` – unlabeled test set  
- `sample_submission.csv` – required output format  

Each row contains:

- **ID** – unique identifier  
- **TEXT** – concatenated spans with the `[SNIPPET]` delimiter  
- **LABEL** – 0 or 1 (training set only)

This task is challenging because:

- Some span pairs are very short, giving limited stylistic evidence.
- Topic and content differences can overshadow stylistic signals.
- Different authors may still adopt similar tone or register (e.g., formal narration).
- We are not given author IDs, metadata, or genre information—only raw text.

Authorship verification and related SotA work often rely on:

- Transformer-based models (e.g., RoBERTa, DeBERTa) with pairwise inputs.  
- Stylometric feature sets with SVMs or logistic regression.  
- Character-level CNNs and language models that capture subword patterns.

My approach is a lighter-weight model built around TF–IDF and a linear classifier, designed to be simple and reproducible but still reasonably competitive.

## Approach

### Feature Representation

I used a simple but effective text representation:

- **TF–IDF vectorization** over the `TEXT` column  
- **Word n-grams:** 1–2 (unigrams and bigrams)  
- `min_df=2`, `max_df=0.9`, and `sublinear_tf=True`  

This representation captures local word patterns and downweights extremely rare or extremely common terms.

### Model

For the final system, I used a **linear SVM (LinearSVC)** inside a scikit-learn `Pipeline`:

- `Pipeline([("tfidf", TfidfVectorizer(...)), ("svm", LinearSVC())])`  

Linear SVMs work well with high-dimensional, sparse TF–IDF features and are a common baseline for document classification and stylometry tasks.

### Training Strategy

1. Split the training data into **train/validation** using `train_test_split` with `test_size=0.2` and stratification on the label.  
2. Fit the TF–IDF + SVM pipeline on the training split.  
3. Evaluate Macro-F1 on the validation split as a proxy for generalization.  
4. Finally, retrain the pipeline on the full training set (`train.csv`) and generate predictions for `test.csv`.

This approach is motivated by simplicity, interpretability, and ease of reproduction.

## Error Analysis

To better understand the model’s behavior, I looked at predictions on the validation split and inspected some misclassified examples.

Common error patterns:

1. **Short span pairs.** When both spans are very short, there is little stylistic signal, and the classifier often guesses incorrectly.  
2. **Topic-driven confusion.** Pairs written by the same author on very different topics sometimes look dissimilar; the model may predict 0 even though the label is 1.  
3. **Generic style.** Texts with very generic narrative or expository style (e.g., simple, declarative sentences with common vocabulary) can cause false positives, predicting 1 when the actual label is 0.

## Future Work

If we had more time, we would explore:
- Transformer-based models (e.g., RoBERTa) that take the two spans as separate inputs and learn a joint representation.
- More stylometric features, such as character entropy, POS tag distributions, and sentence-length statistics.
- Cross-validated model selection, including hyperparameter tuning for the SVM.
- Ensembling several diverse models (Logistic Regression, SVM, and a transformer) to improve robustness.
-These directions are all natural extensions of the current baseline and likely to outperform the simple TF–IDF + LinearSVC system used here.
