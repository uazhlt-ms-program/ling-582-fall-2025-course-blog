## Summary

For this class competition, the task is to predict whether two text spans, separated by the token `[SNIPPET]`, come from the **same author (1)** or from **different authors (0)**.  
This is a stylometry and authorship-matching problem framed as binary classification.

The dataset includes three files:  
- `train.csv` (labeled data)  
- `test.csv` (unlabeled data)  
- `sample_submission.csv` (format template)

Each row contains an ID, a merged text field, and a binary label in the training set.

---

## Approach

For the initial draft submission, our team (Data Minds) developed a simple baseline using a **Kaggle Notebook**.

### Steps:
1. Uploaded the dataset files (`train.csv`, `test.csv`) to Kaggle.  
2. Loaded the data with pandas.  
3. Converted the text to numerical features using **TF–IDF** with:  
   - word n-grams (1,2)  
   - character n-grams (3,5)  
4. Trained a **Logistic Regression** classifier with balanced class weights.  
5. Used a small train/validation split to estimate Macro-F1.  
6. Retrained on the full training data and generated predictions for the test set.  
7. Exported `submission.csv` from Kaggle and uploaded it to the leaderboard.

This formed our valid baseline submission.

_See [the rubric](https://parsertongue.org/courses/snlp-2/assignments/rubrics/class-competition/final/#approach)_
