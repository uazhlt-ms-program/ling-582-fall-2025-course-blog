## Task Summary
This task is a binary classification problem where each example contains two text spans separated by the marker `[SNIPPET]`.  
The goal is to predict whether both spans were written by the **same author (1)** or **different authors (0)**.

## Approach (Initial Baseline)
For the initial submission, we built a simple baseline model using:
- TF–IDF features  
- Logistic Regression classifier  

This baseline was used to generate our first leaderboard submission.
